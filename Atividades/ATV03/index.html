Glossário Técnico

HTML
Linguagem de marcação utilizada para estruturar páginas web.
CSS
Linguagem utilizada para definir a apresentação visual de páginas web.
JavaScript
Linguagem utilizada para adicionar comportamento e interatividade às páginas.
PHP
Linguagem de programação amplamente utilizada no desenvolvimento web.
PostgreSQL
Sistema gerenciador de banco de dados relacional.
